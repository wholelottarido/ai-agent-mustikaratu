Pesan galatnya konsisten: Context size has been exceeded. Server llama.cpp membagi jatah konteks ke beberapa slot paralel. Satu percakapan di portal ini memakan sekitar 9–10 ribu token, jadi dua permintaan serentak sudah melewati jatahnya.

Bukan batas modelnya, tapi setelan servernya. Menaikkan --ctx-size dan --parallel di server akan menaikkan angka ini. Memperpendek instruksi di sisi aplikasi juga membantu.
